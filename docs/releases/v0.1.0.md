## What's new

First release.

- Speed test: 100 MB, 1 GB or 5 GB past the system cache; average, maximum and minimum write and read speed, live
  chart, every block checked.
- Real capacity: quick check (about a minute for any size, data is put back) and full check (fills free space,
  no administrator rights).
- Repair of fake drives: one exFAT or FAT32 partition of the real size.
- Free, total, declared and verified real size of each drive.
- Languages: English, Русский, Español, Deutsch, 中文. Updates from GitHub, Support button.

## Что нового

Первый релиз.

- Тест скорости: 100 МБ, 1 ГБ или 5 ГБ мимо системного кэша; средняя, максимальная и минимальная скорость записи и
  чтения, живой график, сверка каждого блока.
- Реальный объём: быстрая проверка (около минуты при любом объёме, данные возвращаются на место) и полная проверка
  (заполняет свободное место, без прав администратора).
- Исправление поддельных носителей: один раздел exFAT или FAT32 на реальный объём.
- Свободный, общий, заявленный и проверенный реальный объём каждого носителя.
- Языки: English, Русский, Español, Deutsch, 中文. Обновления с GitHub, кнопка «Поддержать».

## Install

- macOS (Apple Silicon): download the `.dmg`, drag the app to Applications; on the first start right-click → Open.
- Windows 10/11 (x64): download the `-windows-x64.zip`, unpack, run `UsbMemoryCheker.exe`.

## Установка

- macOS (Apple Silicon): скачайте `.dmg`, перетащите программу в «Программы»; при первом запуске — правый клик →
  Открыть.
- Windows 10/11 (x64): скачайте `-windows-x64.zip`, распакуйте, запустите `UsbMemoryCheker.exe`.
