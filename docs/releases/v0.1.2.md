## What's new

- **The full check is much faster on fake drives.** After every 1 GB it reads back a few samples, and once the drive
  starts losing data it stops writing (within about 1-2 GB) and checks what was written. A fake "256 GB" card with
  17 GB of real memory now takes about 40 minutes instead of more than 10 hours.
- **More accurate real size** on fakes that wrap writes around: the check measures the real size directly and never
  counts a damaged part as usable.
- **Check after repair.** After a repair the window offers to run the full check on the repaired drive, to confirm
  the new size is right.
- **Faster I/O:** test data is prepared and verified in a second thread while the drive is busy, so fast drives are
  tested sooner. The speed test now uses exactly the chosen size (100 MB is 100 MB).
- On a fake drive the full check can damage files that are already on it: back them up first, or use the quick
  check, which restores everything it overwrites.

## Что нового

- **Полная проверка намного быстрее на поддельных носителях.** После каждого 1 ГБ она читает обратно несколько
  участков и, как только носитель начинает терять данные, прекращает запись (в пределах 1-2 ГБ) и проверяет
  записанное. Поддельная карта «256 ГБ» с 17 ГБ настоящей памяти теперь проверяется примерно за 40 минут вместо
  10 с лишним часов.
- **Точнее реальный объём** у подделок, которые «заворачивают» запись на начало: проверка измеряет реальный объём
  напрямую и никогда не считает повреждённую часть годной.
- **Проверка после исправления.** После исправления окно предлагает сразу запустить полную проверку исправленного
  носителя, чтобы убедиться, что новый размер верный.
- **Быстрее ввод-вывод:** тестовые данные готовятся и сверяются во втором потоке, пока носитель занят, поэтому
  быстрые носители проверяются быстрее. Тест скорости теперь пишет ровно выбранный объём (100 МБ — это 100 МБ).
- На поддельном носителе полная проверка может повредить файлы, которые уже на нём лежат: сначала сохраните их
  или используйте быструю проверку — она возвращает на место всё, что перезаписала.

## Install

- macOS (Apple Silicon): download the `.dmg`, drag the app to Applications; on the first start right-click → Open.
- Windows 10/11 (x64): download the `-windows-x64.zip`, unpack, run `UsbMemoryChecker.exe`.

## Установка

- macOS (Apple Silicon): скачайте `.dmg`, перетащите программу в «Программы»; при первом запуске — правый клик →
  Открыть.
- Windows 10/11 (x64): скачайте `-windows-x64.zip`, распакуйте, запустите `UsbMemoryChecker.exe`.
