## What's new

- The app is now called **UsbMemoryChecker** (it was UsbMemoryCheker), and so is its repository:
  https://github.com/DeMoZ/UsbMemoryChecker. Your settings are kept.
- On macOS an updated copy keeps its old folder name `UsbMemoryCheker.app`; to get the new name, install from the
  `.dmg` and delete the old app.

## Что нового

- Программа теперь называется **UsbMemoryChecker** (была UsbMemoryCheker), репозиторий тоже:
  https://github.com/DeMoZ/UsbMemoryChecker. Настройки сохраняются.
- На macOS обновлённая копия остаётся в старой папке `UsbMemoryCheker.app`; чтобы было новое имя, установите
  программу из `.dmg` и удалите старую.

## Install

- macOS (Apple Silicon): download the `.dmg`, drag the app to Applications; on the first start right-click → Open.
- Windows 10/11 (x64): download the `-windows-x64.zip`, unpack, run `UsbMemoryChecker.exe`.

## Установка

- macOS (Apple Silicon): скачайте `.dmg`, перетащите программу в «Программы»; при первом запуске — правый клик →
  Открыть.
- Windows 10/11 (x64): скачайте `-windows-x64.zip`, распакуйте, запустите `UsbMemoryChecker.exe`.
